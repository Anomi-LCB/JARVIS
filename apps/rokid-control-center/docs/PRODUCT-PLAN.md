# Rokid Visual Device Studio 계획

## 최종 목표

사용자가 Android, ADB, 부트 슬롯, 패키지 이름을 몰라도 자신의 Rokid 안경 상태를 눈으로 이해하고, 안전하게 편집하고, 저장하고, 되돌리고, 검증된 소프트웨어를 직접 배포할 수 있는 로컬 Windows 제어센터를 만든다.

## 제품 원칙

1. 쉬운 모드에는 결과와 영향만 보여준다. 명령어와 원시 값은 전문가 모드에 둔다.
2. 변경 전에 현재 상태를 자동으로 캡처한다.
3. 여러 설정을 적용하다 실패하면 이미 바뀐 항목도 원래대로 되돌린다.
4. 복구 방법이 증명되지 않은 쓰기 작업은 버튼을 제공하지 않는다.
5. 제조사 비밀키에 의존하지 않고, 향후 사용자 소유 키와 사용자 서버로 전환한다.
6. 모든 변경·백업·업데이트 검사는 로컬 감사 기록에 남긴다.

## 단계

### 1. 로컬 제어 기반 — 완료

- 단일 Windows EXE
- USB/ADB 장치 탐지와 상태 표시
- 밝기, 무선, 회전, 화면 대기, 입력, 앱 제어
- 논리/접근 가능 전체 백업
- 로컬 감사 로그와 업데이트 ZIP 검사

### 2. 시각 편집과 PC 화면 제어 — 완료

- 용도별 시각 모드
- 현재 설정을 사용자 모드로 저장
- 적용 전/후 비교
- 부분 실패 자동 롤백
- 직전 모드 한 번에 되돌리기
- 480×640 원본 픽셀을 640×480 가로 보기로 회전하는 자동 재연결 화면 미러링
- PC 마우스 탭·스와이프·길게 누르기
- 화면이 있는 앱 자동 구분과 PC 화면에서 실행
- 194개 System/Secure/Global 설정 시각 탐색
- 추천 세부 설정 카드, 변경 전 스냅샷, 직전 변경 되돌리기

### 3. 복구 패키지 — 안전 게이트

- stock boot/init_boot/vendor_boot/vbmeta/super 이미지 확보
- fastboot/부트로더 장치 식별과 드라이버 진단
- 슬롯별 복구 절차 및 실제 복구 훈련
- 파일 해시와 기기 일치 검증

이 단계가 완료되기 전에는 시스템 파티션 쓰기와 실제 OTA 적용을 열지 않는다.

### 4. 사용자 소유 소프트웨어와 업데이트

- 사용자 소유 서명키와 관리 에이전트
- 재현 가능한 펌웨어/앱 빌드
- 로컬 HTTPS 매니페스트와 패키지 저장소
- 단계적 배포, A/B 건강검사, 자동 롤백

### 5. 사용자 서버와 여러 기기 관리

- 상호 인증된 로컬/사설 서버
- 기기 그룹, 정책, 예약 업데이트
- 상태 대시보드와 장애 복구
- 외부 제조사 서버 없이 동작 가능한 운영 경로

## 현재 안전 경계

부트로더는 열려 있지만 현재 Android 세션에는 루트 권한이 없다. 따라서 접근 가능한 설정과 앱은 제어할 수 있으나, 원시 파티션 백업·시스템 이미지 쓰기·커스텀 OTA 실제 적용은 복구 패키지가 완성될 때까지 잠근다.
